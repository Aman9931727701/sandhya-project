Key Vulnerabilities & Bugs

1. Critical SQL Injection (Universal) CWE-89

In check.php, index.php, tcourse.php, scapply.php, and adcourse.php, user inputs (such as $_POST['n'], $_POST['p']) are concatenated directly into SQL queries: 

// Vulnerable code in check.php:
$q = "select * from teacher where temail='".$n."' and tpassword='".$p."'";
$sq = mysqli_query($cn, $q);

Fix: Replace all mysqli_query calls with prepared statements using $stmt = $cn->prepare(...) and $stmt->bind_param(...).

2. Plaintext Password Storage and Screen Exposure CWE-256

Passwords are inserted into MySQL directly as raw text. In sstudent.php (line 135), the student dashboard literally echoes the student's password in plain text on screen: 

// In sstudent.php line 135:
echo ' <br>STUDENT PASSWORD:'.$r['spassword'];

Fix: Use PHP's built-in password_hash($pa, PASSWORD_DEFAULT) on registration and password_verify($p, $hash) on login.

3. Hardcoded Administrative Credentials CWE-798

In check.php lines 6-12, administrator authentication bypasses the database completely and relies on hardcoded strings: 

if($n=='argus' && $p=='academy') {
    $_SESSION['a'] = $n;
    $_SESSION['aid'] = session_id();
    header("location:admin.php");
}

Fix: Move administrative users into an authenticated table with role-based access control (RBAC).

4. Logic Bug: Inefficient Double Fetching Code Logic

In multiple scripts (e.g., index.php lines 124-128, adcourse.php lines 115-121), the author checks for records by consuming the first row using mysqli_fetch_array(), then re-executes the entire database query: 

// Redundant execution across 10+ pages:
if(mysqli_fetch_array($sq)>0) {
    $sq=mysqli_query($cn,$q); // Re-running query over database
    while($r=mysqli_fetch_array($sq)) { ... }
}

Fix: Use mysqli_num_rows($sq) > 0 to test result count without consuming rows or re-querying.

5. Validation Bug: strlen($p>0) Typo Syntax Bug

In teacher.php (line 135) and student.php (line 134), the phone validation function contains a misplaced parenthesis: 

// In teacher.php line 135:
if(preg_match($pc,$p) && strlen($p>0)) // Checks strlen(true), which evaluates to 1!

Fix: Correct to strlen($p) > 0.
